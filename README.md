# AIOps Command

AIOps Command is a dark-mode-first Flutter dashboard for AI operations monitoring. It provides mock real-time KPIs, routing health, activity logs, AI-driven insights, Firebase email/password authentication, Firestore-backed user profiles, a custom launcher icon, and a native splash screen.

![Flutter](https://img.shields.io/badge/Flutter-3.x-02569B?logo=flutter)
![State](https://img.shields.io/badge/State-Riverpod-blue)

## Features

- Onboarding flow with code-driven Flutter illustrations.
- Firebase Auth sign in, sign up, sign out, and password reset.
- Firestore profile creation and profile age updates under `users/{uid}`.
- Dashboard with date filtering, KPI cards, system health, routing lanes, request volume, and recent activity.
- Activity log screen with severity and service filtering.
- AI Insights screen with actionable recommendation cards.
- Settings workspace for profile, API keys, notifications, documentation, and sign out.
- Custom Android/iOS app drawer launcher icon from `assets/icon/app_icon.png`.
- Native dark splash screen generated by `flutter_native_splash`, including Android 12+ resources.
- Smoke tests for model behavior, mock repositories, and Firebase config consistency.

## Design System

- Strict dark mode with near-black background `#050505`.
- Border and surface-tone hierarchy instead of heavy shadows.
- Cyan and green accents for command, status, and monitoring states.
- Monospace styling for log timestamps, metadata, and terminal-like text.

## Architecture

- `go_router` with `StatefulShellRoute` for bottom-tab navigation.
- `flutter_riverpod` and `riverpod_generator` for app state and generated providers.
- Repository interfaces plus mock repository implementations for dashboard, activity, and insights data.
- Firebase Auth and Cloud Firestore for account and profile workflows.

## Setup

### Prerequisites

- Flutter SDK 3.x
- Firebase CLI
- FlutterFire CLI
- Android Studio or Xcode for platform builds

### Install Dependencies

```bash
flutter pub get
```

### Regenerate Riverpod Providers

Run this if provider source files change:

```bash
dart run build_runner build --delete-conflicting-outputs
```

### Regenerate Native Splash

Run this if `assets/icon/app_icon.png` or the `flutter_native_splash` config in `pubspec.yaml` changes:

```bash
dart run flutter_native_splash:create
```

### Firebase

The app currently contains generated Firebase options for project `aiops-command-87453`.

For Android:
- `android/app/google-services.json` is present.
- `android/app/build.gradle.kts` applies `com.google.gms.google-services`.
- The Android application id is `com.example.aiops_command`.

For iOS:
- `lib/firebase_options.dart` contains the iOS Firebase app config.
- The Xcode bundle id is `com.example.aiopsCommand`.

Before production use, confirm in Firebase Console:
- Email/Password provider is enabled under Authentication.
- Cloud Firestore database exists.
- Firestore rules allow authenticated users to create/update their own `users/{uid}` document.

Example development rules:

```text
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, create, update: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```
